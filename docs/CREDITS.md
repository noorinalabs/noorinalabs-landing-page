# Media credits & provenance

Internal provenance record for third-party media committed to this repository.

These credits are **not** rendered on the site. Where an asset is in the public
domain (CC0), no on-page attribution is legally required; this file exists so the
source, author, and license of every committed image remain auditable.

## Hero photograph — homepage (`/`)

- **File:** `src/assets/hero-yazd-dome.jpg`
- **Subject:** Dome interior of the Jameh (Friday) Mosque of Yazd, Iran
- **Source:** Wikimedia Commons — `File:Dome_of_Jamh_Mosque,_Yazd,_Iran.jpg`
  (<https://commons.wikimedia.org/wiki/File:Dome_of_Jamh_Mosque,_Yazd,_Iran.jpg>)
- **Author:** Erik Albers (Wikimedia Commons user `Dreirik`), own work
- **License:** CC0 1.0 — Creative Commons Zero, Public Domain Dedication
- **Modifications:** downloaded once from the native-resolution original
  (3466 x 2306) and downscaled to a 1920 px-wide JPEG source. The committed
  source is re-encoded to responsive AVIF / WebP (JPEG fallback) at build time
  by `astro:assets`; the Wikimedia CDN is never referenced at runtime.
- **Integration:** Direction C (Architecture) hero, issue #144.
